# 负责任使用指南

AI_image2 用于获得授权的电商视觉生产，不应被用于欺骗消费者、侵犯肖像权或规避平台规则。

## 使用要求

- 仅上传你有权处理的商品、人物、商标和背景素材。
- 使用真人或虚拟试穿能力前，应取得人物肖像和素材使用授权。
- 不得生成或传播非自愿私密影像、冒充真实人物的欺骗性内容或违法商品素材。
- 不得把创意推断的商品结构、颜色、配件或细节描述成真实拍摄事实。
- 上架前人工检查商品真实性、人体结构、服饰穿插、文字、商标和跨视角一致性。
- 遵守所选模型、Provider、电商平台和目标国家或地区的规则。
