# M5 平台与规模化生产实施计划

**目标：** 在现有 M0–M4 可追溯生图闭环上，补齐主流国内外平台规则、CSV 批量建品与套图生产、成本运营报表、租户级并发控制，以及可选的本地 ComfyUI 执行适配器。

**边界：** 平台规则是带版本和来源说明的中台默认值，不宣称官方认证；ComfyUI 只作为模型执行节点，不接管商品、规则、任务、审核和资产；M5 不包含自动发布商品。真实平台规则仍需上线前复核，真实成本和质量门槛仍需用用户 API Key 与 30 SKU 基准验证。

## 任务 1：扩展首批平台规则包

- 增加京东、拼多多、抖音电商、Shopify、Temu、Shopee、Lazada、eBay 规则包。
- 所有规则包沿用不可变版本、编译快照与历史追溯机制。
- 用预置包测试验证 slug 唯一、关键元数据与主图规则可编译。

## 任务 2：CSV 批量导入与生产

- 增加批量作业、逐行结果和状态模型。
- 接收 UTF-8 CSV，校验 SKU、商品名、参考图资产、平台/品类/品牌规则和模型配置。
- 每行幂等创建或复用商品，编译生产计划并排队；部分失败不回滚成功行。
- 提供预检、执行、详情查询和可下载错误 CSV。

## 任务 3：成本与生产运营报表

- 基于生成步骤的真实记录聚合总成本、任务量、成功率和平均成本。
- 支持按日期范围、Provider、模型、平台与 SKU 过滤，返回日趋势和分组明细。
- 前端提供运营页，避免把估算费用伪装成账单结算数据。

## 任务 4：并发控制与 ComfyUI 节点

- 增加可配置的全局和 Provider 并发上限，worker 领取租约前检查在执行数量。
- 增加 ComfyUI HTTP 适配器：上传参考图、提交参数化工作流、轮询历史并下载结果。
- API Key 对 ComfyUI 可选；仍通过统一模型配置和能力契约管理。

## 任务 5：生产控制台与验证

- 增加批量生产和成本报表页面、导航入口及状态反馈。
- 增加 M5 浏览器流程：上传 CSV → 执行多 SKU 多平台任务 → 查看逐行结果 → 查看成本报表。
- 运行后端测试、前端测试、lint/build、Docker 健康检查和 M1–M5 Playwright。
- 在功能分支提交，合并 `main`，验证合并结果并清理已合并分支。

## 实施结果

- 8 个新增平台规则已加入不可变规则包体系，当前共覆盖 11 个平台默认包。
- CSV 作业支持最多 500 行、预检/执行、逐行状态、部分成功和错误 CSV。
- 成本报表按币种隔离，展示 Provider 回传或估算值、日趋势和 Provider/模型/平台/SKU 明细。
- worker 已实施共享数据库并发闸门；ComfyUI 已支持工作流 bindings、参考图上传、异步历史轮询和结果下载。
- 验证结果：66 项后端测试、10 项前端测试、lint、生产构建、Compose 健康检查及 M1–M5 五条 Playwright 流程通过。
